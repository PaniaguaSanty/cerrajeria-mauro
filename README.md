## 📌 Descripción

Desarrollo freelance de un sitio web institucional para una cerrajería local. El proyecto es una **landing page rápida, responsive y accesible**, enfocada en presentar los servicios del negocio y habilitar una comunicación directa con el propietario desde cualquier dispositivo.

> Solución personalizada para un comercio local, priorizando simplicidad, rendimiento y experiencia móvil.

---

## 🧠 Contexto del proyecto

El cliente necesitaba una presencia digital para su negocio con los siguientes objetivos:

| Objetivo | Solución aplicada |
|---|---|
| 📈 Aumentar visibilidad en internet | Landing optimizada para SEO básico y carga rápida |
| 🛠️ Mostrar servicios claramente | Sección dedicada de servicios con iconografía SVG |
| 📲 Facilitar el contacto | Accesos directos a WhatsApp y otros canales |
| 📱 Accesibilidad desde móviles | Diseño mobile-first completamente responsive |

- ✅ Página principal con presentación del negocio

## 🎨 Decisiones de diseño

### ⚡ Simplicidad tecnológica
HTML, CSS y JavaScript puro — sin frameworks ni dependencias innecesarias, para máxima portabilidad y facilidad de mantenimiento.

### 🚀 Rendimiento
Estructura liviana optimizada para tiempos de carga mínimos, ideal para usuarios con conexiones lentas o dispositivos de gama media.

### 📱 Responsive Design
Enfoque *mobile-first*: el sitio fue diseñado primero para pantallas pequeñas y luego adaptado progresivamente a tablets y desktops.

### 🔧 Escalabilidad
La arquitectura modular del proyecto permite incorporar nuevas secciones, funcionalidades o integraciones de forma sencilla y sin refactorizaciones mayores.
