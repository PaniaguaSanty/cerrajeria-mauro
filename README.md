📌 Descripción

Desarrollo de un sitio web institucional para una cerrajería local, creado con el objetivo de mejorar su presencia digital y facilitar el contacto con potenciales clientes.

El proyecto consiste en una landing page clara, rápida y completamente responsive, diseñada para presentar los servicios del negocio y permitir una comunicación rápida con el propietario.

Se trata de una solución personalizada para un comercio local, priorizando simplicidad, rendimiento y accesibilidad.

🧠 Contexto del proyecto

El cliente necesitaba una presencia digital para su cerrajería con el objetivo de:

aumentar visibilidad en internet
mostrar claramente los servicios ofrecidos
facilitar el contacto con nuevos clientes
brindar información accesible desde dispositivos móviles

La solución fue desarrollar una landing page optimizada para dispositivos móviles, enfocada en ofrecer información clara y accesos rápidos de contacto.

🎨 Decisiones de diseño

Durante el desarrollo se priorizaron los siguientes aspectos:

Simplicidad tecnológica

Se utilizó HTML, CSS y JavaScript puro para evitar dependencias innecesarias.

Rendimiento

Optimización para carga rápida y bajo consumo de recursos.

Responsive Design

Adaptación del sitio a diferentes tamaños de pantalla.

Escalabilidad

Organización del proyecto para permitir agregar nuevas secciones o funcionalidades fácilmente.
